# タスク管理アプリ v5
初回(環境作成): `python -m pip install -r requirements_ctk.txt`
実行ファイル作成: `start_task_app_ctk.bat`
起動: 実行ファイルから(実行ファイルと同階層に_internalとtasks.dbが必要。)

- 右上のタスク追加は「既存メインへサブ追加」を初期表示
- タスク一覧の＋サブは対象メインを選択済みで直接表示
- ダッシュボードはシームレスなタイトル行デザイン
- 期限切れ・今週・来週・残件
- 高速スクロール、カレンダー、SQLite保存
- 追加画面の切替順を「既存メインへサブ追加」「新規メインタスク」へ変更
