# タスク管理アプリ v6

## 追加した設定タブ
- スクロール速度: 1-30、初期値5。右側に現在値表示。ダッシュボード・タスク一覧へ即反映。
- 表示倍率: 90% / 100% / 110% / 120%。初期値100%。
- タスク表示密度: コンパクト / 標準 / ゆったり。初期値標準。
- タスク追加時の初期選択: 既存メインへサブ追加 / 新規メイン。初期値は既存メインへサブ追加。
- 標準期限: 今日 / 3日後 / 1週間後 / 2週間後 / 期限なし。初期値1週間後。
- 標準重要度: 高 / 中 / 低。初期値中。
- 完了タスクを非表示: ON/OFF、初期値ON。全件表示へ反映し、完了タブでは完了済みを確認可能。
- 削除時に確認する: ON/OFF、初期値ON。

設定は `settings.json` に自動保存されます。
タスクデータは `tasks.db` に保存されます。

## 起動
初回: `python -m pip install -r requirements_ctk.txt`
通常起動: `start_task_app_ctk.bat`
EXE化: `build_exe.bat`
